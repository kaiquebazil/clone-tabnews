# clone-tabnews

Implementação de um clone do TabNews para fins de estudo de arquitetura e boas práticas.

## 🚀 Funcionalidades

- Sistema de postagens e comentários
- Integração com API
- Testes automatizados
- Arquitetura robusta

## 🛠️ Tecnologias Utilizadas

- Next.js
- React
- Node.js
- Jest

## 📦 Como Executar

1. Clone o repositório
2. Instale as dependências: `npm install` ou `pnpm install`
3. Inicie o projeto: `npm run dev` ou `pnpm dev`
